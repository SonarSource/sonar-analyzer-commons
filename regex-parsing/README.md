SonarSource Analyzers Regular Expressions (REGEX) parser
=========================
Classes that parse regular expressions and support shared regex checks.
Source adapters exist for Java, PHP, and Python. Feature support is explicit in
each adapter; do not assume that all dialects accept the same syntax.
See [AGENTS.md](AGENTS.md) for the parser flow and test locations.
